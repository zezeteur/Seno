# Seno - Application Flutter

Une application Flutter moderne avec une interface utilisateur élégante.

## Prérequis

- Flutter SDK (version 3.0.0 ou supérieure)
- Dart SDK
- Un éditeur de code (VS Code, Android Studio, etc.)

## Installation

1. Assurez-vous d'avoir Flutter installé sur votre système
2. Exécutez `flutter pub get` pour installer les dépendances
3. Lancez l'application avec `flutter run`

## Structure du projet

```
lib/
  main.dart          # Point d'entrée de l'application
```

## Fonctionnalités

- Interface moderne avec Material Design 3
- Compteur interactif
- Thème personnalisable
- Design responsive

## Développement

Pour lancer l'application en mode développement :

```bash
flutter run
```

Pour générer les fichiers nécessaires pour Android et iOS :

```bash
flutter create .
```
